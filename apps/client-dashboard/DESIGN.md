# Emora merchant workspace

Mode: Operate. The user pinned Shopify-style merchant navigation, fast tables and a sticky save bar. This implementation follows that explicit direction rather than proposing a different visual identity.

Dark forest header, pale sage sidebar and a warm off-white workspace. White tables and form panels; restrained green active states, text-plus-dot status badges and tabular currency. DM Sans with local system fallbacks. Compact 13px base, 25px page titles, 11px metadata, rounded controls and hairline dividers. Lucide icons throughout.

Home begins with an ordinary greeting and period picker, a single sales overview with four metrics and a daily chart, an actionable task strip and recent orders. A small setup checklist supports new merchants. No fabricated live sales, comparisons or improvement claims.

Mobile: collapsible sidebar, horizontally scrollable tables, stacked editor panels and a full-width save bar. Keyboard search uses Ctrl/Cmd K and a native dialog with focus containment. Respect reduced-motion preferences.
